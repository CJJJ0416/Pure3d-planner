# 方案 A：显式分层地图接口

确认日期：2026-11-04。当前选择 A，场景生成和规划集中在 vst_global_planner，点云编码器采用 PTv3。

```text
多帧 LiDAR + 相对位姿、时间、观测有效性
  → PTv3 → 位姿对齐与历史 Attention → 空间特征 F
  → 地图解码头：分层代价、支撑有效性、真实支撑高度
  → 预测地图 + 观测覆盖标记
  → 轻量 3D 地图 CNN + 相对目标/状态 → SRU → vx、vy、wz
```

先用对齐的 Tomography 标签监督 PTv3、历史融合和地图解码头。冻结这三个模块，再训练地图 CNN、SRU 和策略头。冻结参数时，观测历史与输出地图仍随时间更新。后续可保留地图监督并做小学习率联合微调。

首版无 VAE/KL，目标信息只进入导航部分。局部地图保留同 XY 的多个支撑高度，坐标保持米制和重力对齐。未知、未观测与无支撑分别记录。奖励查询的 None→0 不作为安全感知标签，障碍高代价不能因选层阈值被过滤出数据集。

此设计记录描述当时的方案，当前单帧 PTv3 和地图解码器进度以服务器训练文档为准。干净 mesh/PCD 用于生成教师标签，不能作为部署时 LiDAR 的直接替代输入。

完整 A/B 历史比较保存在 [PTv3 A/B 历史比较](../../../docs/PTV3_TOMOGRAPHY_AB_AND_ENVIRONMENTS.md)。
