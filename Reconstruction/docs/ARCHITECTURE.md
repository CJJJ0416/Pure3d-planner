# RECON：Mesh 监督、固定区块与条件 Flow

```text
完整大地形 Mesh → 完整 PCD → 固定核心／上下文块
完整块 → 冻结 PTv3 → 空间适配器 → 完整 latent → 几何解码器

完整大地图 → 全局 Subtraction → 同一边界的缺损块
缺损块 → 冻结 PTv3 → 冻结 Filter → 条件适配器 → c
高斯噪声 + c → 时间条件 Flow → 完整 latent → 同一几何解码器
保留原点 + 新增表面点 → 修复后的 PCD
```

每份实际缺损块独立编码一次。Utonia Tiny 输出 486 维特征，经 inverse 对齐 Filter 保留点。6 cm 聚合网格经过两次卷积压缩，得到 24 cm、32 通道 latent。网格由固定核心与上下文边界定义，包括没有输入点的位置。

解码器不读取完整高分辨率特征旁路，仅使用 latent 与查询坐标，按 24→12→6→3→1.5 cm 层级输出表面概率与单元内偏移。内部 128 维查询特征用于几何解码，本轮不导出下游 Cost 特征接口。

阶段 A 训练完整几何自编码，阶段 B 冻结 A，训练条件适配器与速度场。B 同时接受标准 Flow MSE 和终点几何监督。冻结解码器的参数不更新，但其对 latent 的导数必须保留。

最终生成点按实际 XYZ 所属的全局 1.5 cm 单元去重，保留原点优先。部署采样默认 16 步 Euler，另测 4／8 步。采样步内不重复 PTv3 或 Filter。课程与精确 Loss 见 [监督与损失](SUPERVISION_LOSS.md)。
