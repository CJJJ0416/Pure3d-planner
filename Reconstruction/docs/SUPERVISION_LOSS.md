# Mesh 监督与两阶段 Loss

## 标签与查询

唯一几何 GT 是完整大地形 Mesh。每个尺度的查询单元通过三角形与单元精确裁剪得到 `surface=0/1`。正单元目标坐标为单元内距离中心最近的 Mesh 表面点，偏移是该坐标减单元中心。0 只表示单元无目标表面经过，不表示机器人可通行。

将正单元目标坐标关联到最近的完整 PCD 点，保存其全局索引。该点在当前缺损输入经 Filter 后未保留时为 `MISSING`，否则为 `OBSERVED`。缺失分组不会改写 Mesh 的正标签，所有完整表面始终参加监督。

`geometry_batch(...)` 每个尺度返回 `xyz[Q,3]、label[Q]、offset[Q,3]、size、group[Q]`。`Q=4096`，分组编码为：

| group | 含义 | 阶段 A | 阶段 B |
|---|---|---:|---:|
| 0 | 已观测表面 | 2048 | 1024 |
| 1 | 缺失表面 | 0 | 1024 |
| 2 | 距表面 24 cm 内的真实空单元 | 1024 | 1024 |
| 3 | 全局真实空单元 | 1024 | 1024 |

A 不使用缺损分组，正样本统一采样。B 若缺失或观测组为空，2048 个正样本全部来自另一组。小样本池允许有放回采样。负样本由完整 Mesh 排除表面单元，不从 PCD 采样间隙推断。监督查询中心在核心区内，上下文供编码使用。

## 阶段 A：几何自编码

令 B 表示各组内平均 BCE。正负部分各占一半，近表面负组与全局负组按 2∶1 归约：

\[
L_{surface}=\tfrac12 B_{positive}+\tfrac12(2B_{near}+B_{global})/3.
\]

仅对正样本计算偏移损失：

\[
L_{offset}=\operatorname{mean}_{positive}\operatorname{SmoothL1}(\hat\delta/s,\delta/s),\quad\beta=0.1.
\]

\[
L_A=\tfrac15\sum_{s\in\{.24,.12,.06,.03,.015\}}(L_{surface,s}+L_{offset,s}).
\]

空间适配器与几何解码器从头训练，PTv3 冻结。解码器只读取 latent 与查询坐标，完整高分辨率特征没有旁路。

## 阶段 B：Flow 与终点几何

完整目标 latent 由冻结 A 生成，按训练集均值与标准差归一化为 z1。高斯噪声为 z0，t 均匀采样：

\[
z_t=(1-t)z_0+tz_1,\qquad L_{FM}=\operatorname{mean}\|v_\theta(z_t,t,c)-(z_1-z_0)\|^2.
\]

一次速度场预测得到终点估计：

\[
\hat z_1=z_t+(1-t)v_\theta(z_t,t,c).
\]

先把终点估计反归一化，再经冻结解码器，得到同一组查询的表面分类与坐标偏移。B 的正组 BCE 和偏移都按 `(observed + 2×missing)/3` 归约，负组仍按 `(2×near + global)/3` 归约。空分组不参加加权均值，剩余权重重新归一化。

\[
L_B=L_{FM}+\lambda_{geo} L_{geometry}(D_{geo}(\hat z_1)).
\]

`lambda_geo = 0.1 × min(1, epoch_progress/5)`，其中 `epoch_progress` 从第 1 轮起点的 0 开始，到第 5 轮结束为 5。一个 batch 只执行一次速度场预测和一次终点解码，不在训练中展开 16 步采样。

冻结采用 `requires_grad_(False)`，不能在这段解码外围使用 `no_grad`。这样 A 参数不变，但梯度可从几何 Loss 回传至 Flow。`flow_matching_loss(...)` 返回总 Loss 和分项日志。噪声与时间可显式传入，用于可复现的函数验收。

首版不引入 Chamfer、语义分类或 VST 训练 Loss。最终通行性通过独立的固定网格 VST 评估。

实际数据中，某些粗尺度核心可能没有近表面空单元。此时该组为空，不参与加权归约，原本 1024 个近表面负样本名额转给全局真实空单元。每层仍保持 2048 正、2048 负和 4096 总查询，不丢弃区块，也不把表面单元改成负标签。
