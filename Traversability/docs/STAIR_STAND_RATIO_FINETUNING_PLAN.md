## 2. 按教师的真实规则设计数据

当前教师 `kernel_size=7`，站立格数阈值为：

```text
T(r) = int(49 × stand_ratio) - 1
```

教师首先判定净空和局部坡度。只有进入台阶分支、且最大高度差未超过 `step_max` 时，才比较 7×7 邻域内满足局部坡度要求的格数 n 与 T(r)。当 n < T(r) 时判为障碍。

局部坡度的高度差阈值是 `1.2 × resolution × tan(slope_max)`。因此可站立格数也随 `slope_max` 改变。站立比例不是独立于坡度的“楼梯宽度参数”。

这决定了增强要覆盖三种情况：

1. 同一楼梯改变 stand_ratio，GT 确实发生变化的样本。
2. 同一楼梯改变 stand_ratio，GT 基本不变的样本，例如宽平地、站立条件一直充足的楼梯。
3. 受 step_max 或净空限制的楼梯，即使降低 stand_ratio 也不能通行。

三类均保留原生标签。不能只训练第一类，否则网络可能学成“改变 stand_ratio 就必须改变所有 cost”。教师的骨架、距离代价和膨胀后处理照常执行，差异损失使用最终教师实际差值，不人为规定所有最终 cost 必须逐点单调。

## 3. 先修正实际几何随机化，再扩充数据

当前 `/home/cjh/Pure3D_ws/common/geneator/wfc_connections.py` 中，直楼梯把采样踏步深度保存为 `sampled_tread_depth_m`，实际构造却使用：

```text
n = ceil(楼层高度差 / 目标单级高度)
actual_tread_depth = (固定可用长度 - landing) / (n + 1)
```

所以直楼梯的采样深度没有直接参与 Mesh 构造。往复楼梯使用采样深度，但还会被可用长度截断。旋转楼梯的实际踏面深度由半径、转角和级数共同决定。仅修改 JSON 的踏步深度随机区间不够。

改造目标是先决定可实现的单级高度、实际踏面深度和宽度，再计算梯段长度与连接空间。直楼梯按生成器当前约定满足 `rise=n×riser`、`run=(n+1)×tread+landing`。场地尺寸、平台和楼层连接随之调整。旋转楼梯记录内侧、中线、外侧的实际踏面深度，不能用一个采样字段代替真实几何。

第一批建议范围如下。这些是实验采样范围，不是机器人能力声明。

| 几何量 | 初始范围或组合 | 用途 |
|---|---|---|
| 单级高度 | 0.08–0.38 m | 覆盖 step_max 两侧的样本 |
| 实际踏面深度 | 0.12–0.50 m | 改变站立窗口内平坦格数，作为主要变化轴 |
| 梯段宽度 | 0.40–1.60 m | 覆盖窄于与宽于约 0.7 m 教师窗口的情况 |
| 类型 | 直梯、往复梯、旋转梯 | 分离踏步变化与楼梯形状变化 |
| 周围结构 | 无栏杆、有栏杆、单侧墙、上下平台 | 保留真实边界和骨架形成的上下文 |
| 方位与落格位置 | 随机 yaw、随机 XY 网格相位 | 避免固定朝向及 0.1 m 教师网格对齐模式 |

一个几何家族包含同一小型建筑的三版楼梯，主要改变实际踏面深度，保持单级高度、级数、宽度、机器人条件和场景风格不变。建筑占地与平台连接随梯段长度调整。其他家族再改变高度、宽度、栏杆和类型，避免把所有变量同时改变后无法解释效果。

首批为 8 个训练家族、3 个验证家族、3 个测试家族，每家族三版，共 42 个小型建筑。训练家族先配置 4 个直梯、2 个往复梯、2 个旋转梯，验证和测试各覆盖三种类型。每个场景包含楼梯、上下平台及相邻楼面，保留全局粗几何输入。每个 seed 输出 overview 和楼梯侧视图。

同家族的所有变体归入同一个划分。既有 seed 20261127 等已查看案例只作为回归集，不加入新训练数据，也不当作新的独立测试。

沿用 Mesh 表面采样 0.03 m、输入 PCD 体素 0.05 m、教师地图分辨率 0.1 m。几何尺寸改变后重新采样并运行 VST，不能缩放 PCD 后沿用旧 cost。每个场景保存实际尺寸和 stand 判定分支的统计，后者仅用于分析数据覆盖，不作为学生输入。

### 4.1 每份几何交叉多组机器人条件

每个条件包包含 4 个联合随机锚点。四维分别分层抽样并独立打乱，降低参数之间的人为相关性。随机种子由 geometry seed、condition-bank ID 和独立条件种子共同确定，避免“某种楼梯只配某类机器人”。同一份几何交叉多个条件包，每种楼梯类型均覆盖各参数区间。

每个锚点构造 9 组条件：原锚点，加上四个参数各自的低值、高值对照。变更一个参数时，其他三个参数逐值保持不变。

```text
随机条件 c0
  ├─ clearance_low / clearance_high
  ├─ slope_low / slope_high
  ├─ step_low / step_high
  └─ stand_low / stand_high
```

4×9=36 组，再加入 4 个固定对照，总计每次训练使用 40 组。固定对照为 nominal、low_stand、strict_stand 和当前查看的 `[0.5,0.6,0.4,0.05]`。固定对照维持旧知识和可比较的曲线，其余条件提供随机覆盖。

每份几何先离线生成 3 个条件包。固定 4 组共享，随机条件名额共 108 个，最多缓存 112 组不同教师结果。训练按 epoch 切换条件包，每步仍计算 40 组条件。条件随机化发生在教师数据生成时，训练时只抽取已经生成匹配 GT 的条件。不能在 DataLoader 中随意扰动条件后复用原标签，也不能在不同参数的 GT 之间线性插值制造新标签。

VST 几何只构建一次，不同条件复用 ground、ceiling 等几何中间量并重新计算 cost。学生的局部与全局几何编码结果也供全部条件共享，不为每组参数重复跑 PTv3。额外教师计算、存储和模型解码耗时分别记录。

### 4.2 一半覆盖全范围，一半跨越真实门槛

每包 4 个锚点中，2 个采用全范围低/高值配对，2 个采用教师临界值附近配对。锚点本身仍联合随机。临界配对在该几何、该锚点其他参数固定后确定，保证模型见到的是不同背景条件下的响应。

- stand_ratio：统计进入台阶判定分支的邻域可站立格数 n。`T(r)=int(49r)-1`，在 n 固定时，原始判定的切换位置是 `r*=(n+2)/49`。从训练楼梯中落在允许范围内的门槛取样，在两侧取不同有效格数档位。仍由完整教师计算最终 cost，不根据门槛手填标签。
- step_max：在教师实际局部最大高度差门槛附近取对照值，建议两侧间隔 0.01–0.04 m。使用教师梯度量，不能只用生成器声明的级高替代。
- slope_max：根据教师实际坡度/可站立格数变化选择邻近条件，初始两侧间隔 0.02–0.08 rad，并覆盖与 stand_ratio 的交互。
- clearance_min：根据楼梯边缘和平台通道的实际教师响应配对，初始间隔 0.05–0.15 m，同时保留远离边缘的稳定区域。

若某个锚点在当前几何内没有范围内的临界事件，该配对使用全范围取样，并保留稳定标签。所有取值均在上述训练范围内，不将负值或超范围值裁剪成大量重复样本。

临界配对的统计只来自训练几何。验证/测试参数及条件种子预先固定，测试几何不得反过来选择训练条件。全图标签继续保留，临界事件只用于生成有辨识度的条件，不用于删掉教师点。

### 4.4 FiLM 如何从随机监督中得到增强

当前 `/home/cjh/Pure3D_ws/Traversability/models/model.py` 的 FiLM 为：

```text
c = [clearance_min, slope_max, step_max, stand_ratio]
(gamma, beta) = MLP(c / condition_scale)
F_conditioned = (1 + gamma) × F_geometry + beta
cost = sigmoid(CostHead(F_conditioned))
```

四维缩放沿用旧 checkpoint 的 `[1.0,0.5,0.3,1.0]`。保持输入尺度，便于继承已有调制能力。随机参数本身不保证模型使用参数，还需同一几何上的配对差值监督：

```text
Delta_pred = prediction(XYZ, c_high) - prediction(XYZ, c_low)
Delta_GT   = VST(XYZ, c_high)        - VST(XYZ, c_low)
L = L_absolute + lambda × L_difference(Delta_pred, Delta_GT)
```

沿用 D 的 lambda=1、参数权重 `[1,2,1,2]` 和变化/稳定区域均衡归约。每一参数先独立归约，再加权，避免大量 stand 配对仅凭数量淹没其他参数。实际梯度同时训练 FiLM 和 CostHead，不强行放大 gamma/beta，也不把每处 cost 变化强制设成单调。

第一阶段保留原 FiLM 结构。前两轮冻结 PTv3，其余查询、融合、FiLM 和代价头共同适应新配对。随后解冻编码器小学习率微调。验证时看最终 cost 对参数的响应幅度是否接近教师，以及楼梯通道是否恢复，而不是只看 FiLM 权重数值变大。

如果随机配对版本仍存在响应不足，增加独立结构对照 `C_residual_film`：在原代价头第一个 128 维隐藏层的 GELU 之后再加一处条件调制。

```text
h128 = GELU(W1 × F_conditioned + b1)
h128_new = h128 + delta_gamma(c) × h128 + delta_beta(c)
```

新增条件分支最后一层权重和偏置置零，初始 `h128_new=h128`。保留原 FiLM、编码器、查询层和 CostHead 权重，以保持初始化时的旧预测函数。该版需要显式的 checkpoint 结构迁移和版本标识。它与 C 使用同一初始化来源、相同数据和训练步数，仅比较第二处 FiLM 的作用。先完成数据对照，再决定是否保留这一结构。

## 5. 三个实验区分“重复学习”和“学到新关系”

| 实验 | 楼梯训练来源 | 条件表 | 回答的问题 |
|---|---|---|---|
| A：重复采样对照 | 原有 6 个训练建筑的楼梯 | 现有 D 的 40 组 | 只是多看旧楼梯是否就有效 |
| B：几何增强 | 新训练家族的楼梯 | 同 A | 真实踏步几何多样性是否有效 |
| C：几何与随机参数配对 | 与 B 完全相同的几何 | 第 4 节的随机条件包，每步 40 组 | 联合随机和临界配对是否额外改善 |

三组每轮固定 342 个块，206 个来自相应楼梯块，136 个来自原 6 个训练建筑的全场景块。使用同样的分组采样策略，组内必要时有放回抽样。楼梯块包含周围几何和完整原生查询标签，保留高低代价及平台边界。这个比例是块访问比例，不声称是查询点比例。

采样器已增加上述分组采样入口，旧配置仍沿用全数据随机无放回。原场景回放用于保持平地、坡道、边界等已学能力。楼梯增强不额外删除标签，也不引入高度连续、地表匹配或射线覆盖筛选。

三组均继承原版全部模型权重，使用 `train.py --initialize`。优化器和学习率调度器重新开始。不能用 `--resume` 开启这个新实验，因为当前 resume 会沿用 checkpoint 内的数据和训练配置。

| 训练项 | 首轮筛选设置 |
|---|---|
| 轮数与更新数 | 每版 20 epoch，batch=2，每轮 171 次更新，共 3420 次 |
| 头学习率 | 1e-4 |
| 编码器学习率 | 1e-5 |
| 前 2 轮 | 冻结 PTv3，训练 QueryPool、融合层、FiLM 和 CostHead |
| 第 3–20 轮 | 编码器小学习率参与微调，使用预设 50 轮余弦周期的前半段 |
| 第 21–50 轮 | 选定版本保持相同数据配比和损失，继续原余弦周期 |
| 优化与精度 | AdamW，weight_decay=0.05，BF16，workers=2 |
| 绝对代价损失 | 原 SmoothL1，beta=0.1 |
| 条件差异损失 | 沿用 D 的变化/稳定区域均衡方式，lambda=1，参数权重 `[1,2,1,2]` |

三组使用完全相同的损失和模型结构，先观察数据增强效果。变化/稳定区域只决定差异项如何归约，不删除监督标签。筛选阶段不同时新增骨架头、连通损失或手工单调约束。

三组每步条件数量和更新数相同。C 具有更多离线教师条件，教师准备预算不同，必须另报。有效条件对数量和点数也可能不同，记录实际训练耗时。按验证结果将选定版本从第 20 轮继续到第 50 轮，不预先认定 C 必胜。若差异接近或波动明显，增加相同预算的第二随机种子复现。需要结构对照时，再加入 C_residual_film，从同一原版初始化并使用同样调度。新测试集用于方案固定后的最终评估。

## 6. 以跨踏步连通和条件响应验收

所有模型使用同一查询 XYZ、同一条件、同一邻接、同一起终点和固定 cost 阈值 0.3。邻接参数在观察预测前固定，保留已使用的 0.3 m 与 0.45 m 两种诊断口径，不修改运行中的规划器。先报告几何图本身的连通情况，再统计代价造成的断裂。0.45 m 图是跨踏步代价诊断，不是机器人实际通行证明。

关键指标为：

1. GT 连通端点对中，预测被代价截断的比例。衡量当前用户观察到的问题。
2. GT 不连通但几何图连通的端点对中，预测错误放行的比例。区分真正拟合与整体压低 cost。
3. 同一楼梯四参数扫描的教师/学生 cost 曲线、变化点差值 MAE、响应幅度和方向，以及稳定点差值 MAE。重点报告 stand_ratio，并增加未见联合参数的结果。
4. 沿上下楼方向的低代价通道曲线与最小所需通行阈值，给出 GT、原版、D50、A/B/C 的同视角图。
5. 楼梯整体、踏步连接、教师骨架和非楼梯回放场景的代价误差，分别报告。

每 5 轮完整验证时记录原有综合分数和新增楼梯连通指标。初始选优约定为：相比微调前原版，验证集错误放行率增加不超过 2 个百分点，非楼梯 MAE 增加不超过 5%。在满足该约定的 checkpoint 中优先选择楼梯断裂率最低者，再按 stand 差值 MAE、整体 MAE 排序。若没有候选满足，则不宣布本轮改善。这些容差是预设实验判据，不是安全标准。多个几何家族的连通率先按家族分别统计，再等权汇总，避免楼梯更多的场景支配结果。

第 20 轮按各版本迄今 best.pt 的完整验证结果选方案，继续训练使用该版本第 20 轮 last.pt，保留此前 best.pt 及选优记录。最终交付整个 1–50 轮中验证选出的 best.pt，同时保留第 50 轮 last.pt。若新增评估显示训练方案无改善，保留原版作为当前推荐模型，报告观察到的差异。

同一批验证数据同时评价原版和 D50。若 B/C 都改善，但 C 没有稳定优于 B，只能说明楼梯几何覆盖有帮助，不能归因为随机条件配对。C 优于 B 时，再看 stand、slope、step、clearance 的分项响应确定改善来源。若三组都不能改善，再检查特征查询分辨率和通道损失，而不是先继续增加 epoch。
