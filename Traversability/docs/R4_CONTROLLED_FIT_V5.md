# R4受控拟合

该实验只诊断同一R4折返梯的可拟合性。R4进入训练，结果不能作为未见建筑泛化证据。

入口：

```bash
cd /home/cjh/Pure3D_ws
/home/cjh/miniconda3/envs/pure3d-ptv3/bin/python -u -m Traversability.experiments.r4_controlled_fit
```

配置为`Traversability/configs/r4_controlled_fit_v5.json`，全部结果写入`runs/traversability/r4_controlled_fit_v5/`。不创建监控定时任务，不运行规划器。

## 数据

从四参数解耦实验的第30轮best.pt初始化。输入完整建筑几何，只加载原分块中包含R4查询的三个核心块。固定1440个Tomogram支撑查询点，原索引顺序不变。额外4个原始PCD瓶颈点只前向观察，不参与训练损失。

33组训练条件包含基准和每个参数8个额外值，另有12组单参数留出条件。原生教师从完整PCD建立几何，逐条件计算代价。保持障碍代价50、距离曲线p=2、归一化0–1、interval_free=0.5以及其他原生参数。

固定同一水平支撑片、相同高度与原生XY八邻域配对。跨核心块边保留。配对只定义空间差值损失，不改变教师标签，不删除监督点，不生成楼梯跨阶边。

## 对照

| 版本 | 条件 | 损失 |
|---|---|---|
| A | 仅基准 | 原始逐点SmoothL1 |
| B | 仅基准 | 逐级均衡点值 + 0.5空间差值 |
| C | 基准与四参数扫描 | 基准B + 0.25其他条件B均值 + 0.5条件差值 |

逐级均衡点值项：8级踏步各自先平均，然后合计占60%。入口、转折平台、出口各自先平均，然后合计占40%。空间差值拟合学生邻点差与教师邻点差，变化区（绝对GT差大于0.02）与稳定区等权。全部SmoothL1的beta为0.1。

C的其他条件先按参数组平均。条件差值为每轴9个取值的36对，各参数等权，变化与稳定区等权。基准损失始终保持系数1，没有随条件数稀释。

## 更新和选择

所有可学习参数更新，固定体素取点，模型采用保留梯度的eval模式，关闭随机层且保持初始化归一化统计。编码器BF16，FiLM和CostHead FP32。

三个查询块组成真batch3，一次几何编码供全部条件共享。输出按原始query_index还原，所有配对在统一顺序上计算，因此跨块配对也参与反向传播。四个观察点始终不进入损失。

AdamW使用新优化器，编码器LR=5e-6，其他LR=5e-5，weight decay=0.05。三组从一开始采用1500步余弦调度，各跑300步。每25步评估并保存完整best.pt/last.pt。

第300步按相同基准指标选择版本：

`S = 0.6 × 8级踏步宏平均MAE + 0.4 × 3处平台宏平均MAE + 0.25 × 均衡空间差值MAE`

差值小于1e-6时按A、B、C顺序。获胜版本从第300步last.pt继续到1500步，保留优化器和调度器状态。初始化参与最终best选优。各版本300步的预测单独保存为pilot_predictions.npz。

## 结果

progress.json随流水线更新当前阶段、训练损失与最近评估。各版本evaluations.json记录逐级代价、低代价走廊偏差、0.3/0.5/0.6阈值错误、空间差值和留出条件指标。C每25步记录基准与加权辅助条件损失的梯度夹角及各模块梯度范数。

最终使用正式完整PCD推理入口加载最佳完整权重，核对查询位置迁移。原始PCD只有几何定义的支撑面且与GT ground对应的位置参与该项评价，其余GT保留未知。这是最终评价的标签定义，不影响任何训练监督点。

输出summary.json、REPORT.md、逐部位CSV、训练曲线、重力俯视GT/训练前/训练后/误差图、四参数与瓶颈点曲线，以及完整prediction/prediction.pcd。原始权重与旧实验保留。
