# 正式DC方案与唯一消融

更新于2026-11-11。正式方案为DC有跨阶边，唯一消融为DC无跨阶边。两者使用同一入口和相同地图，不保留其它搜索、表面提取或轨迹优化试验模式。

## 输入与几何

输入为地图坐标系的 `x、y、z、trav_cost` PCD，cost已由机器人条件化网络预测并归一化到0–1。条件顺序为 `clearance_min、slope_max、step_max、stand_ratio`，更改条件后应重新预测cost。

原点固定的0.1m体素对XYZ和cost取算术平均。显式ROI只按配置选择占用体素，不自动裁剪。几何场对实测占用体素集合计算有符号EDT，不填洞、不膨胀，不读取OBJ或原始Mesh。这个场描述观测壳，不等于真实建筑实体内外或有射线可见性的TSDF。

DC在穿过零等值面的体素单元内求Hermite/QEF顶点，连接为网格。cost由同一份均值体素PCD最近邻附着。搜索顶点为 `surface + 0.1m × outward_normal`，保留原表面对应索引，不在移动后重新查询cost。

## 邻接与消融

先删除cost超过上限的节点，仅保留两端都合法的原三角网格边。预测cost原值和原三角邻接不变。正式方案再添加满足以下条件的双向边：

1. 两端法向与反重力方向夹角不超过 `slope_max`。
2. 高差大于0.05m且不超过 `step_max`。
3. 水平间距不超过0.3m。
4. 两端来源PCD点在反重力方向 `interval_free=0.5m` 内没有其它已占用体素阻挡。射线跳过来源自身的体素，只使用已有占用，不补全未知空间。该条件只作用于新增边，不剪除原三角网格节点或边。

阈值集中在 `PlannerConfig`，不在各实验入口分别硬编码。这些是候选运动连接条件，不包含独立机器人碰撞或控制器可执行性求解。消融只关闭新增边，不改变节点、cost、起终点、权重或GPMP。

世界起终点表示PCD支撑位置，先定位输入体素锚点，再从对应来源中选定合法朝上DC表面节点。所有节点索引和吸附距离保存到结果。A*只保留C++单向实现，公式见 [权重说明](ASTAR_COST_WEIGHT.md)。

## GPMP

A*的原表面对应点作为GP节点，避免把0.1m搜索偏移重复加入机体高度。以反重力方向建立局部坐标系，保留全部A*节点，在±0.1m高度带内用0.4m尺度正则得到C2高度曲线。GPMP只优化水平位置与速度，整段水平走廊半径0.2m。

连续cost在优化后的支撑XYZ查询。输出机体轨迹统一沿反重力方向平移0.5m，速度在统一平移前后相同。没有使用地面绝对零点，也不重新查slice。GP先验、插值、速度软因子和SciPy稀疏TRF/LSMR参数保持已验收版本。

## 输出

- `map/voxel_cost.pcd`：供连续cost查询的均值点云。
- `map/dc_surface_cost.pcd`：DC搜索表面与cost。
- `map/graph_view.npz`：原边、新增边、连通分量，供消融可视化。
- `map/map.json`：来源、点数、图与分阶段时间。
- `with_step/`：正式方案的查询、配置、路径、轨迹和指标。
- `without_step/`：显式启用消融时保存相同格式。
- `summary.json、REPORT.md、overview.png`：一次运行的汇总与绘图。

`astar_path.csv`为实际搜索坐标，`support_path.csv`为原表面对应点。`gpmp_support.csv`为优化后的支撑曲线，`gpmp_trajectory.csv`为加0.5m反重力偏移后的机体参考轨迹。cost积分和长度各自记录，GPMP目标值不当作A*目标值。
