# GPU 体素统计 Filter 训练档案：2026-11-13

已完成实现、六场景恢复、独立统计缓存、50 epoch训练和三版对照。配置为 `Filter/configs/train_scoring_voxel.json`，结果为 `runs/filter_scoring_voxel_20261113/`。

## 实现与输入

输入仅为地图系XYZ。Tiny冻结/eval，输出486维体素特征，inverse恢复原始点。GPU在0.05、0.15、0.5 m三个世界对齐尺度计算点数和26邻格占用率，按尺度交错组成六维特征。点数使用log1p，中心点计入点数，中心体素不计入占用率。归一化仅使用Train统计。

统计通过唯一整数体素键计数和邻格查表实现，每张完整PCD仅计算一次。Tiny继续按4×4×3 m核心加1 m上下文编码。三维相对坐标加六维统计经9→32→32分支，与128维投影拼接后评分。输出保留全部原始点序，不自动筛除。

新增geometry_mode为knn、relative、voxel。旧权重按use_knn恢复，原分支状态可以严格加载。GPU推理共享XYZ，编码特征不再往返CPU。两张真实地图的无统计版复测输出与原归档逐位相同。

## 数据和训练

同seed重建24变体，共2,175,141点、333盒。全部标签、来源组、结构类别和核心索引与旧缓存一致，四个测试变体XYZ与归档一致。新统计缓存约53 MiB，只读复用原约2 GiB冻结特征。CPU/GPU参考最大误差4.7684e-7。统计缓存CUDA累计0.1545 s，缓存循环墙钟0.4155 s，不含进程启动和模块导入。

Train为821100–821103，Val为822100，Test为823100。评分头从零训练，seed42，50 epoch、1400更新。保持原来源/结构均衡SmoothL1、AdamW、LR1e-3、5% warmup和cosine，batch8、workers4、BF16。

best来自epoch15、step420，last为epoch50、step1400。loss从0.361115降至0.016215。完整训练入口128.40 s，训练循环累计51.70 s，CUDA分配峰值1.892 GiB。两份checkpoint的编码器均与原缓存逐张量相同。

KNN采用同机历史记录。本轮无统计与体素版使用相同GPU驻留推理路径复测。整体提速也包含取消特征CPU/GPU往返的收益，不能全部归因于体素统计。total_s含进程内模型加载、读取、分块、统计、编码、评分和保存。GPU阶段使用CUDA Event计时，主机提交区间可能重叠，不能简单求和。
