# 全点评分网络

当前参考为 `geometry_mode=relative`，只使用三维相对坐标，不计算六维统计。KNN 与体素统计保留为显式对照。模型身份见 `../configs/baseline.json`。

输入只有地图系 XYZ。编码器全程冻结并处于 eval 模式。颜色和法向输入按 Tiny 接口填零，Mesh、来源、语义、标签和运动时间不进入网络。

| 步骤 | 输入 → 输出 |
|---|---|
| 上下文编码 | `[N_context,3]` → Tiny 五层特征 upcast → `[M,486]` |
| 可训练投影 | `486→128`，LayerNorm、GELU |
| 恢复核心点 | 通过 `inverse` 取回每个核心点的体素特征 |
| 几何分支 | relative：体素内相对坐标 `3→32→32`。knn/voxel：相对坐标3维＋各自统计6维 → `9→32→32` |
| 评分头 | 拼接 160 维 → `128→64→1`，Dropout 0.1、Sigmoid |
| 合并 | 核心点按 `point_index` 写回原始 PCD 行序 |

486 维来自 `18+36+72+144+216`。Tiny 内部 `grid_size=0.01`、`scale=0.5`，约 2 cm 物理网格。该内部体素编码保留 inverse，区别于在输入端删除原始点。

六维统计为邻居平均距离、第 16 近邻距离、第 64 近邻距离、0.15 m 和 0.5 m 半径邻居数，以及平均距离与远邻距离之比。使用完整上下文计算。均值和标准差只从训练集统计。

knn模式支持cuda和显式cpu后端。cuda使用float64 GPU KDTree精确搜索和只返回计数的半径内核，输出与原六维float32接口保持相同，不改变归一化或网络权重。CUDA半径计数利用完整子树AABB进行排除或批量计数，不保存查询数×点数的邻居矩阵。已在66个独立测试上下文和两张真实地图上核对原模型评分逐位相同。

历史配置未设置 geometry_mode 时，`use_knn=false` 使用 relative 模式，跳过六维统计的生成、读取、归一化和推理查询。三维相对坐标由编码器体素映射直接得到，不依赖 KNN。评分头仍拼接为 160 维。历史 checkpoint 缺省 `use_knn=true`，按原结构加载。

新增显式 `geometry_mode`：knn、relative、voxel，优先于历史 use_knn。voxel 在原始地图坐标上计算0.05、0.15、0.5 m三个尺度的点数和邻格占用率。每个尺度输入 `log1p(count)` 与邻格非空数/26。中心体素不计入占用率，中心点计入点数。没有观测点的格子仅表示未占用的观测单元，不产生删除标签。

GPU 实现通过唯一整数体素键计数，并对占用体素查找26个邻格，按65536个占用体素分块。统计完整PCD一次并恢复到原始点序，不计算点间距离矩阵。新统计独立缓存，原冻结特征与监督只读共享。部署同一份GPU XYZ同时供统计与Tiny编码使用，半精度冻结特征直接交给评分头。

冻结缓存保存核心需要的原始 486 维体素特征、inverse、相对坐标和几何统计。投影、几何分支和评分头在线训练，不缓存它们的输出。

当前损失为 beta=0.1 的 SmoothL1。先在同一来源组内对存在的结构语义分别求点均值，再对结构均值和存在的来源组依次取均值。来源组包括建筑、静止物体、准确断连结构、悬空/配准残影和动态残影。当前数据没有主动生成断连对照，该空组不参与平均。

训练前向不执行硬筛选。部署默认返回所有原始点的评分。显式阈值选择属于后处理，不改变评分模型。

Filter 与 Traversability 当前仍是独立训练的模型。共享特征交给 RECON 是后续接口设计，不代表本轮已经实现单编码器端到端流水线。实测结果见 [训练档案](TRAINING_ARCHIVE_20261112.md)。
