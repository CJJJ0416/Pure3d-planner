# 代码审查与源码清理

日期：2026-11-17。

当前保留链路为 Faster-LIO → LIO 独立盒子和稳定上下文 → KNN → PTv3 + cost head → A* → SCAN。局部条件保持 `[0.5,0.4,0.2,0.0]`，模式 4 保持严格 `cost < 0.8`，SCAN 保留原局部优化。

## 清理范围

- 移除 Reconstruction 源码、配置、方案和架构中的活动引用。更新根目录说明与网络结构图。
- 移除项目测试、一次性 ROS 验证脚本和仓库内第三方测试源码。同步处理指向已删除测试目录的 CMake 引用。
- 实验模块保留本地，从 Git 跟踪和本次源码发布中排除。正式训练使用的共享函数迁到 data/training，函数 AST 与原实现逐项一致。
- 保留训练、推理、数据生成、模型定义、原生规划、仿真、控制器、安装外参与 RViz 入口。
- 保留运行必需的传感器方向表、模型和仿真控制策略。数据集、采集包、训练 checkpoint、运行输出和编译产物不随源码提交。

历史 bag 工具中的 `offline/reconstruction` 是 Faster-LIO 建图归档的目录名，不依赖已移除的神经补全模块，保留原数据格式。

删除前的源文件、变更快照、SCAN 上游 Git 元数据及本次验证结果保存在本机 `outputs/maintenance/source_release_20261117/`，该目录不上传。

## 审查修复

| 问题 | 修复 | 验证 |
|---|---|---|
| cost 启动器在取得互斥锁前清理旧进程，并发启动可能互相终止 | 增加启动阶段互斥，在首次 ready 后释放，保留之后显式替换会话的能力 | 持有启动锁时启动第二个会话，确认其拒绝进入清理逻辑 |
| 正式训练导入实验目录的采样和指标函数 | 将被正式调用的函数移入 data/training，排除实验编排与对照脚本 | 提取函数 AST 一致，7 个生产模块导入通过 |
| A* 接收点云没有核对数据长度，异常轨迹消息可能让 Python 回调退出 | 校验 row_step 和 data 长度，捕获无效 B-spline 参数 | 静态检查及清理前既有回归通过 |
| checkpoint 中的训练精度配置可能被误读为实际推理精度 | 模型记录新增 inference.encoder_precision 与 device，保留原训练配置 | 真实 Tiny worker 记录 FP32，固定输入缓存前后差异为 0 |
| 默认地图只指向本机 EOLP 路径，包内同名模型仍使用旧 URI | 保留 EOLP 优先级，增加同源包内副本与缺少 EOLP 时的默认选择 | DAE 与用户指定源文件 SHA256 一致 |
| 删除测试后部分构建规则仍包含不存在的目录 | 删除 SCAN 的测试目标，为第三方测试目录引用增加存在性检查 | 15 个 ROS 包构建通过，GTSAM 关闭测试的 CMake 配置通过 |

人工审查主要覆盖 Entry 接收、调度、缓存、进程管理与 A*/SCAN 交接，以及正式训练依赖和发布入口。对保留的项目 Python、Shell、JSON 与本地导入关系进行静态检查。第三方算法实现保留原有逻辑，本轮检查其测试清理与构建接口。
